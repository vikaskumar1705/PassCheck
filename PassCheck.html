PassCheck

Type a password to see how fast it could be cracked, whether it has leaked before, and how to make it stronger. Nothing you type is stored.

How to improve it

    Stronger versions of your password

    Versions built from your own password are easier to remember, but a fully random one is safer. Do not reuse the same pattern on other accounts.

    Breach check privacy: only the first 5 characters of your password’s hash are sent out. Your real password never leaves this page. Needs internet.
